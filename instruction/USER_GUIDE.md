## Назначение системы

LightHeadless CMS — это система для:
- 📩 **Сбора заявок** с лендингов и форм на сайте
- 📰 **Управления новостями** с поддержкой Markdown
- 🔗 **Интеграции с Битрикс24** для автоматической передачи лидов

## Быстрый старт

### Шаг 1: Запуск CMS

**Вариант A: Готовый бинарный файл**

```bash
# Перейдите в папку cms
cd cms

# Запустите CMS
cms.exe
```

**Вариант B: Запуск из исходников**

```bash
cd cms
go run ./cmd/server
```

**Вариант C: С параметрами**

```bash
cms.exe -port 8080 -db ./cms.db -upload ./uploads
```

### Шаг 2: Проверка работы

Откройте браузер и перейдите по адресу:

```
http://localhost:8080/admin/
```

Если CMS запустилась успешно, вы увидите страницу входа.

## Вход в админку

### Первый вход

При **первом запуске** CMS автоматически создаёт учётную запись администратора и выводит данные в консоль:

```
╔══════════════════════════════════════════════════╗
║          FIRST RUN — ADMIN CREDENTIALS           ║
╠══════════════════════════════════════════════════╣
║  Email:    admin@example.com                     ║
║  Password: xK7mP2qR9nLs                          ║
║  Change password in Settings!                    ║
╚══════════════════════════════════════════════════╝
```

**Важно:** Скопируйте пароль из консоли — он показывается только один раз!

### Вход в систему

1. Откройте `http://localhost:8080/admin/`
2. Введите **Email** (по умолчанию `admin@example.com`)
3. Введите **Пароль** (из консоли)
4. Нажмите **«Войти в систему»**

### Смена пароля

После первого входа настоятельно рекомендуется сменить пароль:

1. Перейдите в **Настройки** (в нижнем меню сайдбара)
2. Нажмите **«Изменить пароль»**
3. Введите новый пароль (минимум 6 символов)
4. Подтвердите пароль
5. Нажмите **«Сохранить настройки»**

## Управление заявками

### Просмотр заявок

1. В меню выберите **Заявки**
2. Откроется список всех заявок с фильтрами

**Отображаемая информация:**
- ID заявки
- Имя клиента
- Телефон
- Email
- Статус (Новая / Отправлена / Ошибка)
- Дата создания

### Фильтрация и поиск

**Фильтры:**
- **Статус** — выберите из списка: Все / Новые / Отправлены / Ошибка
- **Поиск** — введите имя, телефон или email
- **На странице** — выберите количество заявок (20/50/100)

Фильтрация происходит автоматически при вводе (без перезагрузки страницы).

### Детальный просмотр заявки

1. Кликните на значок **«Просмотреть»** (глаз) в строке заявки
2. Или кликните на имя клиента

**На странице заявки:**
- Контактные данные (имя, телефон, email)
- Комментарий клиента
- Статус заявки
- Информация об отправке в Битрикс24 (дата, ответ)
- Кнопка **«Отправить в Битрикс24»** (повторная отправка)

### Изменение статуса

1. Откройте детальную страницу заявки
2. В правой панели выберите нужный статус
3. Нажмите **«Сохранить статус»**

### Удаление заявки

**Из списка:**
1. Наведите курсор на строку заявки
2. Нажмите на значок **«Удалить»** (корзина)
3. Подтвердите удаление

**Из детальной страницы:**
1. В правой панели нажмите **«Удалить заявку»**
2. Подтвердите удаление

⚠️ **Внимание:** Удаление необратимо!

### Экспорт в CSV

1. В списке заявок настройте фильтры (если нужно экспортировать не все)
2. Нажмите **«Экспорт CSV»** в правом верхнем углу
3. Файл `leads-YYYY-MM-DD.csv` загрузится автоматически

**Поля в CSV:**
```
id,name,phone,email,comment,status,created_at,bitrix_sent_at
```

## Управление новостями

### Список новостей

1. В меню выберите **Новости**
2. Откроется список всех публикаций

**Отображаемая информация:**
- Изображение новости
- Дата публикации
- Заголовок
- Краткий анонс

### Создание новости

1. В списке новостей нажмите **«Создать новость»**
2. Заполните форму:

**Обязательные поля:**
- **Заголовок** — до 255 символов
- **Дата публикации** — выберите дату

**Необязательные поля:**
- **Анонс** — краткое описание (до 500 символов)
- **Изображение** — загрузите файл (JPEG, PNG, GIF, WebP, до 5 МБ)
- **Описание** — полный текст в формате Markdown

3. Нажмите **«Опубликовать»**

### Редактирование новости

1. В списке новостей нажмите **«Редактировать»** под нужной новостью
2. Измените необходимые поля
3. Нажмите **«Сохранить изменения»**

### Удаление новости

1. В списке новостей нажмите **«Удалить»**
2. Подтвердите удаление

⚠️ **Внимание:** Изображение новости также будет удалено!

### Markdown редактор

При создании/редактировании новости доступен редактор с поддержкой Markdown:

**Вкладки:**
- **Редактор** — ввод текста в формате Markdown
- **Предпросмотр** — отображение готового HTML

**Справка по Markdown:**

| Синтаксис | Результат |
|---|---|
| `# Заголовок` | Заголовок H1 |
| `## Подзаголовок` | Заголовок H2 |
| `**жирный**` | **жирный** |
| `*курсив*` | *курсив* |
| `- пункт` | Маркированный список |
| `[текст](url)` | Ссылка |
| `` `код` `` | Встроенный код |
| `![alt](img.jpg)` | Изображение |

## Настройки

### Основные настройки

**Путь:** `/admin/settings`

**Параметры:**
- **Название сайта** — отображается в заголовке браузера и сайдбаре
- **Email администратора** — используется для входа
- **Новый пароль** — оставьте пустым, чтобы не менять

### Интеграция с Битрикс24

**Настройка пошагово:**

#### Шаг 1: Создайте вебхук в Битрикс24

1. Войдите в ваш портал Битрикс24
2. Перейдите в **Разработчикам** → **Входящий вебхук**
3. Создайте вебхук с методом `crm.lead.add`
4. Скопируйте URL вебхука

#### Шаг 2: Настройте в CMS

1. В админке CMS перейдите в **Настройки**
2. Прокрутите до раздела **Интеграция с Битрикс24**
3. Вставьте URL вебхука в поле **URL вебхука**
4. Нажмите **«Проверить соединение»**

**Результат проверки:**
- ✅ **Успешно** — вебхук работает, можно включать
- ❌ **Ошибка** — проверьте URL и доступность Битрикс24

5. Включите переключатель **Включить отправку**
6. Нажмите **«Сохранить»**

#### Как работает отправка

1. Клиент заполняет форму на сайте → заявка сохраняется в CMS
2. CMS асинхронно отправляет заявку в Битрикс24
3. Статус заявки обновляется:
   - **Отправлена** — успешно
   - **Ошибка** — не удалось (можно отправить повторно)

#### Повторная отправка

Если заявка не отправилась:

1. Откройте детальную страницу заявки
2. Нажмите **«Отправить в Битрикс24»**
3. Статус обновится автоматически

## Интеграция с сайтом

### Размещение формы на сайте

Добавьте HTML-форму на ваш сайт:

```html
<form action="https://cms.yourdomain.com/api/leads" method="POST">
  <!-- Honeypot для защиты от спама -->
  <input name="website" style="display:none" tabindex="-1">
  
  <!-- Поля формы -->
  <input name="name" placeholder="Ваше имя" required>
  <input name="phone" placeholder="Телефон" required>
  <input name="email" placeholder="Email">
  <textarea name="comment" placeholder="Комментарий"></textarea>
  
  <button type="submit">Отправить</button>
</form>
```

### Поля формы

| Поле | Обязательное | Описание |
|---|---|---|
| `name` | Да | Имя клиента (до 255 символов) |
| `phone` | Да | Номер телефона (до 20 символов) |
| `email` | Нет | Email (валидация формата) |
| `comment` | Нет | Комментарий (до 1000 символов) |

### Отправка JSON (AJAX)

```javascript
fetch('https://cms.yourdomain.com/api/leads', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    name: 'Иван',
    phone: '+7 999 123-45-67',
    email: 'ivan@example.com',
    comment: 'Заявка с сайта'
  })
})
.then(response => response.json())
.then(data => console.log(data));
```

### Получение новостей (API)

**Список новостей:**

```javascript
fetch('https://cms.yourdomain.com/api/news?page=1&limit=10')
  .then(response => response.json())
  .then(data => {
    data.data.forEach(news => {
      console.log(news.title, news.announce);
    });
  });
```

**Детальная новость:**

```javascript
fetch('https://cms.yourdomain.com/api/news/1')
  .then(response => response.json())
  .then(news => {
    console.log(news.title);
    console.log(news.description_html); // Готовый HTML
  });
```

## Частые вопросы

### ❓ Я забыл пароль. Что делать?

**Решение:** Удалите файл базы данных и перезапустите CMS.

```bash
# Остановите CMS
# Удалите файл БД
rm cms.db

# Запустите заново — будет создан новый пароль
cms.exe
```

⚠️ **Внимание:** Все данные будут удалены!

### ❓ Как изменить порт?

**Вариант A: CLI флаг**

```bash
cms.exe -port 3000
```

**Вариант B: Переменная окружения**

```bash
CMS_PORT=3000 cms.exe
```

### ❓ Где хранятся загруженные изображения?

В папке `uploads/` относительно исполняемого файла.

Пример: `cms/uploads/abc123.jpg`

### ❓ Как сделать резервную копию?

Скопируйте файл базы данных:

```bash
# Linux/Mac
cp cms.db cms-backup-$(date +%Y%m%d).db

# Windows (PowerShell)
Copy-Item cms.db cms-backup-$(Get-Date -Format yyyyMMdd).db
```

### ❓ CMS не запускается. Ошибка «port already in use»

Порт 8080 занят другим приложением.

**Решение:** Используйте другой порт:

```bash
cms.exe -port 8081
```

### ❓ Заявки не отправляются в Битрикс24

**Проверьте:**

1. ✅ Включена ли интеграция в настройках
2. ✅ Правильность URL вебхука
3. ✅ Доступность Битрикс24 (проверьте через браузер)
4. ✅ Статус заявки — если «Ошибка», нажмите «Отправить в Битрикс24» повторно

### ❓ Как очистить все данные?

Удалите файл базы данных:

```bash
rm cms.db  # Linux/Mac
del cms.db # Windows
```

При следующем запуске CMS создаст новую БД и сгенерирует новый пароль.
