# 🚀 Быстрый запуск тестового стенда

## Шаг 1: Запустите CMS

```bash
cd D:\Projects\LightHeadless\cms
go run ./cmd/server
```

**Или используйте бинарник:**
```bash
cd D:\Projects\LightHeadless\cms
.\cms.exe
```

✅ CMS доступен по адресу: **http://localhost:8080**

---

## Шаг 2: Откройте лендинг

**Вариант A: Просто откройте файл в браузере**

Дважды кликните на файл `landing/index.html` или:
```bash
cd D:\Projects\LightHeadless\landing
start index.html
```

**Вариант B: Запустите локальный веб-сервер**

```bash
# Python (если установлен)
cd D:\Projects\LightHeadless\landing
python -m http.server 3000

# Откройте: http://localhost:3000
```

---

## Шаг 3: Создайте тестовые новости

1. Откройте админку CMS: **http://localhost:8080/admin/**
2. Войдите (email/пароль из консоли при первом запуске)
3. Перейдите в раздел **Новости**
4. Создайте 2-3 тестовые новости:
   - Заголовок: "Наша новая услуга"
   - Дата: сегодня
   - Анонс: "Мы запустили новую услугу!"
   - Описание: любой текст
   - Изображение: загрузите картинку (опционально)

---

## Шаг 4: Протестируйте лендинг

### Проверка новостей

1. Откройте лендинг
2. Прокрутите до секции **"Последние новости"**
3. Должны отобразиться созданные новости

### Проверка формы

1. Прокрутите вниз до секции **"Свяжитесь с нами"**
2. Заполните форму:
   - Имя: Тест
   - Телефон: +7 999 123-45-67
   - Email: test@example.com
   - Комментарий: Тестовая заявка
3. Нажмите **"Отправить заявку"**
4. Должно появиться сообщение об успехе ✅

### Проверка в админке

1. Откройте **http://localhost:8080/admin/leads**
2. Должна появиться новая заявка со статусом **"Новая"**

## Часто задаваемые вопросы

### ❓ Новости не загружаются

**Проверьте:**
1. CMS запущен и доступен: http://localhost:8080
2. Новости созданы в админке
3. Откройте DevTools → Console → проверьте ошибки

**Решение:**
```bash
# Проверьте API вручную
curl http://localhost:8080/api/news
```

### ❓ Заявка не отправляется

**Проверьте:**
1. Все обязательные поля заполнены
2. CMS запущен
3. Откройте DevTools → Network → проверьте статус запроса

**Решение:**
```bash
# Проверьте API вручную
curl -X POST http://localhost:8080/api/leads \
  -H "Content-Type: application/json" \
  -d '{"name":"Тест","phone":"+7 999 123-45-67"}'
```

### ❓ Ошибка CORS

Если лендинг на другом домене (не localhost), нужна настройка CORS.

**Решение:** В production используйте HTTPS и настройте CORS в CMS.
