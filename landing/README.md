# Тестовый Лендинг для LightHeadless CMS

Простой одностраничный лендинг с интеграцией CMS:
- 📰 **Вывод новостей** из CMS через API
- 📩 **Форма заявки** с отправкой в CMS
- 🎨 **Современный дизайн** на Tailwind CSS
- 📱 **Адаптивная вёрстка** (mobile-first)

---

## Быстрый старт

### Вариант 1: Открыть файл напрямую

Просто откройте файл `index.html` в браузере:

```bash
# Windows
start index.html

# Mac
open index.html

# Linux
xdg-open index.html
```

### Вариант 2: Запустить локальный сервер

**Python:**
```bash
# Python 3
python -m http.server 3000

# Откройте http://localhost:3000
```

**Node.js:**
```bash
npx serve .
# или
npx http-server -p 3000
```

**Go:**
```bash
cd landing
go run -mod=mod github.com/yuin/goldmark@latest # если нужно
# или просто используйте встроенный сервер CMS
```

## Функционал

### Секции лендинга

1. **Header** — навигация с якорными ссылками
2. **Hero** — главный экран с призывом к действию
3. **About** — преимущества компании (3 карточки)
4. **News** — последние новости из CMS (до 6 штук)
5. **Contact** — форма обратной связи
6. **Footer** — подвал сайта

### Интеграция с CMS

#### 1. Получение новостей

```javascript
GET http://localhost:8080/api/news?limit=6

Response:
{
  "data": [
    {
      "id": 1,
      "date": "2026-03-26",
      "title": "Заголовок",
      "announce": "Краткий анонс",
      "image": "/uploads/abc123.jpg"
    }
  ],
  "pagination": {...}
}
```

#### 2. Отправка заявки

```javascript
POST http://localhost:8080/api/leads
Content-Type: application/json

{
  "name": "Иван",
  "phone": "+7 999 123-45-67",
  "email": "ivan@example.com",
  "comment": "Заявка с лендинга"
}

Response 201:
{
  "status": "success",
  "message": "Lead saved"
}
```

## Настройка

### Изменение CMS URL

Если CMS запущен на другом порту или домене, измените переменную:

```javascript
// В конце файла index.html
const CMS_URL = 'http://localhost:8080';
// или
const CMS_URL = 'https://cms.yourdomain.com';
```

### Кастомизация дизайна

Лендинг использует **Tailwind CSS** через CDN. Вы можете менять:

- **Цвета:** замените `brand-600` на другие цвета Tailwind
- **Шрифты:** добавьте Google Fonts в `<head>`
- **Иконки:** используйте emoji или подключите FontAwesome

### Добавление секций

Просто скопируйте структуру существующей секции:

```html
<section id="new-section" class="py-16">
    <div class="max-w-6xl mx-auto px-4">
        <h2 class="text-3xl font-bold text-center mb-12">Новая секция</h2>
        <!-- Контент -->
    </div>
</section>
```

## Особенности

### ✅ Преимущества

- **Нет сборки** — работает напрямую из HTML файла
- **Нет зависимостей** — Tailwind CSS через CDN
- **Адаптивность** — корректно отображается на всех устройствах
- **Валидация форм** — проверка обязательных полей
- **Обратная связь** — анимация загрузки, сообщения об успехе/ошибке

### ⚠️ Ограничения

- **CORS** — если лендинг на другом домене, нужны CORS заголовки в CMS
- **HTTPS** — для production нужен HTTPS (CMS должен поддерживать)
- **Rate limiting** — CMS ограничивает 10 заявок в минуту с одного IP

## Отладка

### Новости не загружаются

1. Проверьте, что CMS запущен: `http://localhost:8080/admin/`
2. Откройте DevTools → Console → проверьте ошибки
3. Проверьте Network tab → запрос к `/api/news`

### Заявка не отправляется

1. Проверьте консоль на ошибки
2. Убедитесь, что все обязательные поля заполнены
3. Проверьте Network tab → статус запроса `POST /api/leads`

### Ошибка CORS

Если видите ошибку CORS в консоли:

```javascript
// В CMS (internal/handlers/api_leads.go) добавьте:
w.Header().Set("Access-Control-Allow-Origin", "*");
```

Или запустите лендинг на том же домене, что и CMS.
